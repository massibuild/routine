# Routine compléments

Petite app perso (PWA) pour suivre la prise quotidienne des compléments : matin, midi, soir.

Installation sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
Sur Android : Chrome → menu ⋮ → « Installer l'application ».

Les cases cochées sont enregistrées sur le téléphone uniquement.
